# Sistema de Locação de Veículos

Projeto desenvolvido em **Java** para praticar conceitos de programação orientada a objetos e manipulação de datas e horários.

## 📋 Sobre o projeto

O sistema simula o processo de locação de um veículo, calculando o valor a ser pago de acordo com o período de utilização.

A regra de cobrança funciona da seguinte forma:

- Locações de até **12 horas** são cobradas pelo valor da hora.
- Locações com duração superior a **12 horas** são cobradas pelo valor da diária.
- Sobre o valor da locação é aplicado um imposto:
  - **20%** para valores de até 100,00.
  - **15%** para valores acima de 100,00.

Ao final, o programa apresenta uma nota de pagamento contendo:

- Modelo do veículo;
- Data e horário de início da locação;
- Data e horário de término da locação;
- Valor da locação;
- Valor do imposto;
- Valor total do pagamento.
